# Prompt 3 - Pedido de rediseño de la carga de datos

**Prompt real del usuario** (adjuntando una captura de pantalla de la pestaña
"Cargar Datos" original):

> quiero que cambies la página de subida de información. El usuario no tiene que
> cargar archivos, tiene que tenre campos (similares al excel que uso) para
> cargar ahí la información. La única información a subir son los precios
> unitarios y el programa o cronograma de obra de dónde sale la curva S base.
> Los demás datos los tiene que cargar en este programa y el programa. Crea
> metadata para probar esto y mostrame cómo quedan las solapas de la página,
> quiero ver el avance de la curva S, el avance del PPC y la frecuencia de las
> CNC antes que empieces a codear y modificar el repo

**Resultado:** maqueta HTML interactiva publicada como Artifact (no se tocó el
repositorio, tal como pidió el usuario) con datos de ejemplo: pestaña de datos
base + registro diario en planilla editable, y las pestañas de Curva S, PPC y
frecuencia de CNC.
